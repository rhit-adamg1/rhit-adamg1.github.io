## Introduction

In this project, you will learn the basics of working with images in general, and what specific tools are available in  Matlab and the Image Processing Toolbox. We'll start by talking about images in general, concepts that can apply to any programming language, then we will dive deeper into the specific Matlab tools at your disposal. At the end of this project, you should be able to: 

<ul>
    <li> Describe what is an image in mathematical terms and know the difference between grayscale, RGB, and HSV. </li>
    <li> Load images, manipulate color channels, perform segmentation, and pre/postprocess images. </li>
    <li> Utilize different types of image tracking and identification. 
</ul>

## Getting Started with Images in Matlab

To start with this project, download the set of images on Moodle (and link here) and save them in your current workspace in Matlab. I recommend you create a folder just for this project so you can keep your scrips and functions organized and in the same place.
